# 🚀 EmployeeManagementSystem

A fullstack web application built with .NET 9 and C# to help a company manage their employees. 
This project includes the backend (server side) which provides the functionality of the business logic built with ASP.NET Core Web API
and the frontend (client side) built using Blazor Web Assembly and MudBlazor library.

## ✨ Key Features

Employee Management System is a software that offers:

* Managing employee's data.
* Managing user's accounts (registering, accessing their profile and updating data).
* Registering job positions and departments.
* Registering assets and employee assigned assets.
* Registering categories for their expenses.
* Tracking Attendance, Leave Requests and Performance Reviews.
* Managing Roles.
* Managing employees payroll.
* Receiving different notifications about their account activity or updates.
* Uploading files.
* Retrieving, adding, updating and deleting.

## 🛠 Tech Stack

* **Language:** C#
* **Framework:** .NET 9 / ASP.NET Core Web API / Blazor Web Assembly / MudBlazor
* **Database:** SQL Server
* **ORM:** Entity Framework Core / LINQ
* **Security:** Authentication (JWT token based, hashed/salted user password).
* **API Documentation:** Swagger

## 🚀 Getting Started

To run this project locally, follow these steps:

1. **Clone the repo:**
git clone https://github.com/yllka-shala/EmployeeManagementSystem.git

2. **Open the solution:**
Open `FinanceApi.sln` in Visual Studio.

3. **Migrate database:**
In Package Manager Console add command Update-Database to create the database in MSSQL.

4. **Run:**
Press `F5` to build and launch the app.
